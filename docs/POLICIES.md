# BrowseKit — Extension policies

This file lists every policy BrowseKit follows and how to check them. The
**generated** section at the bottom is produced from `manifest.json` and
`scripts/validate.mjs`, so it always matches the code.

## How to list the policies

| Command | What it shows |
| --- | --- |
| `npm run policies` | Every policy, generated live: permissions + reasons, host access, CSP, banned APIs, commands, and pass/fail status |
| `npm run policies -- --write` | Same, and refreshes the generated section of this file |
| `npm run validate` | Enforces the policies; exits non-zero on any violation (used by `npm run check` and `npm run package`) |
| `node -e "console.log(require('./manifest.json').permissions)"` | Just the install-time permissions |
| `chrome://extensions` → BrowseKit → **Details** | What Chrome actually granted (permissions, site access, "Allow in Incognito", file access) |
| `chrome://extensions/shortcuts` | Keyboard commands and their current keys |
| **Settings → About** in the dashboard | Version, schema and the permissions the running extension holds |

Chrome-side policies (for administrators): `chrome://policy` lists enterprise
policies that can block, force-install or restrict extensions
(`ExtensionSettings`, `ExtensionInstallBlocklist`, `ExtensionAllowedTypes`,
`RuntimeBlockedHosts`). BrowseKit does not read or set any of these.

## Policies BrowseKit follows

### 1. Local-only data (privacy)
- No backend, external API, AI API, analytics, telemetry, login or remote code.
- Data lives in IndexedDB and `chrome.storage.local`; `chrome.storage.sync` is banned.
- Reader-view text is kept in `chrome.storage.session` (memory) only.
- Favicons come from Chrome's local cache, never from websites.
- Backups are files the user exports; optional AES-256-GCM encryption. See [PRIVACY.md](../PRIVACY.md).

### 2. Minimum permissions
- A permission is added only when a feature needs it and is documented in
  `architecture.md` §4, `PRIVACY.md` and the `WHY` table in `scripts/policies.mjs`.
- No host permissions at install; site access is optional, per site, and revocable.
- Prefer `activeTab` + on-demand `scripting` over persistent access.
- Never: `<all_urls>` at install, `tabGroups`, `history`, `bookmarks`,
  `downloads`, `identity`, `webRequest`, `declarativeNetRequest`, `externally_connectable`.

### 3. No remote or dynamic code (Manifest V3)
- `script-src 'self'`, `object-src 'none'`, `connect-src 'self'`; no `eval`,
  `new Function`, remote imports, CDN assets or inline scripts/styles.

### 4. Safe DOM
- Untrusted text (titles, URLs, imported files, page text) is rendered with
  `textContent` via `h()`; `innerHTML`/`outerHTML`/`insertAdjacentHTML`/`document.write` are banned.

### 5. Honest limits
- When Chrome or a site prevents something (chrome:// pages, Web Store, DRM,
  cross-origin media boost, closed shadow DOM, background-tab discards), the UI says so.

### 6. Chrome Web Store program policies
- **Single purpose:** a browsing-productivity toolkit (tabs, reading, media, page tools).
- **User data:** none collected or transmitted; privacy policy in `PRIVACY.md`;
  "Read your browsing history" (tabs) is used only for features the user invokes.
- **Limited use:** permissions are used only for the stated features.
- **No obfuscation / remote code:** source ships as readable ES modules; no minification required.
- **Accurate listing:** see `docs/store-listing.md` (states limits honestly).

### Optional host access (asked per site at runtime)

- `https://*/*` — only the single site you approve, for automatic Media Boost
- `http://*/*` — only the single site you approve, for automatic Media Boost
- Install-time host permissions: **none**

### Permission allow-list (anything else fails validation)

`storage`, `tabs`, `favicon`, `contextMenus`, `activeTab`, `scripting`, `sessions`, `alarms`, `sidePanel`

### Content Security Policy (extension pages + service worker)

- `default-src 'self'`
- `script-src 'self'`
- `object-src 'none'`
- `base-uri 'none'`
- `form-action 'none'`
- `frame-src 'none'`
- `connect-src 'self'`
- `img-src 'self' data: blob:`
- `media-src 'self' blob:`
- `style-src 'self'`
- `font-src 'self'`

### Banned in shipped source (`src/`)

- network request (fetch) — `\bfetch\s*\(`
- network request (XMLHttpRequest) — `\bXMLHttpRequest\b`
- network connection (WebSocket) — `\bWebSocket\b`
- network connection (EventSource) — `\bEventSource\b`
- telemetry primitive (sendBeacon) — `\bsendBeacon\b`
- eval — `\beval\s*\(`
- new Function — `\bnew\s+Function\s*\(`
- chrome.storage.sync (uploads data to Google) — `chrome\.storage\.sync\b`
- chrome.tabGroups (TabVault must not use tab groups) — `chrome\.tabGroups\b`
- innerHTML/outerHTML assignment (XSS sink) — `\.(innerHTML|outerHTML)\s*[+]?=`
- insertAdjacentHTML (XSS sink) — `\binsertAdjacentHTML\b`
- document.write — `\bdocument\.write\b`
- importScripts — `\bimportScripts\s*\(`
- Literal remote `http(s)://` URLs, except: `^http:\/\/www\.w3\.org\/`
- Bare/remote `import` specifiers (no dependencies) and missing imports
- Inline `<script>`, `<style>`, `style=""` and `on*=""` handlers in HTML
- ES `import`/`export` in content scripts (they must be classic scripts)

### Keyboard commands

- `_execute_action` — Open the BrowseKit popup (default Alt+Shift+B)
- `save-to-watch-later` — Save the current page to Watch Later (default Alt+Shift+W)
- `media-speed-up` — Media: faster (default Alt+Shift+Period)
- `media-speed-down` — Media: slower (default Alt+Shift+Comma)
- `media-speed-reset` — Media: reset speed to 1×
- `media-toggle-play` — Media: play / pause
- `media-toggle-mute` — Media: mute / unmute
- `media-seek-forward` — Media: skip forward
- `media-seek-back` — Media: skip back
- `save-tab-to-vault` — Save the current tab to the last-used TabVault collection
- `open-palette` — Search everything (tabs, TabVault, Watch Later, sessions, actions)
- `snooze-tab` — Snooze the current tab until tomorrow morning
- `media-pip` — Media: picture-in-picture
- `free-memory` — Suspend all background tabs to free memory

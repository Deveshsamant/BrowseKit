# Chrome Web Store listing — BrowseKit

**Name:** BrowseKit — Private Tab Manager, Watch Later & Video Speed

**Short description (≤132 chars):**
Save & search tabs, snooze, watch later, video speed 0.25–16×, reader view and more. 100% local: no account, no tracking.

**Category:** Productivity · **Language:** English

## Description

BrowseKit is an all-in-one browser toolkit that keeps everything on your device.
No account. No servers. No analytics. No AI calls. Just fast tools.

**Tabs**
• TabVault: save a tab, a window or all windows into collections, open them in one click, search, tag and add notes
• Search everything (Ctrl+K): open tabs, saved tabs, Watch Later, sessions and actions in one box
• Snooze tabs until later today, tonight, tomorrow, the weekend or a custom time
• Close duplicate tabs, sort tabs by site, merge windows
• Auto-suspend idle tabs to free memory; auto-close idle tabs into a recoverable list
• Sessions & workspaces with automatic crash-recovery autosaves

**Reading & watching**
• Watch Later queue from the popup, right-click menu or Alt+Shift+W
• Media Boost for HTML5 video/audio: 0.25×–16× speed (any custom value), volume boost where possible, A–B loop, picture-in-picture, resume where you left off, per-site memory and shortcuts
• Reader view: clean, distraction-free article text

**Tools**
• Copy URL/title/Markdown link, clean tracking parameters
• Word count & reading time, link extractor
• Offline QR codes, screenshots of the visible area, print to PDF
• JSON / Base64 / URL / hash / password / case / timestamp tools

**Private by design**
• All data stays in your browser (IndexedDB + local storage), never synced or uploaded
• Optional password-encrypted backups
• Minimal permissions; site access only when you ask for it

Honest limits: extensions can't run on chrome:// pages or the Web Store; volume
boost can't process DRM or cross-origin media without CORS.
